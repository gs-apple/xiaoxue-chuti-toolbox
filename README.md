# 小学出题工具箱 V1.2.5

一款专为小学生设计的全能练习题生成工具，基于 tkinter 桌面应用，支持数学出题、字帖生成、作文浏览、真题下载、英语练习、打赏支持六大模块，一键生成 A4 PDF 练习卷，覆盖 1-12 年级。

## ✨ 主要功能

### 🔤 英语练习模块

**单词记忆 / 课本句子，按 版本 + 年级 + 学期 + 单元 精准生成可打印练习**

**设置项：**
- **版本**：人教版(PEP) / 陕旅版 —— 两套教材独立词库与句型库
- **年级**：三年级 ~ 六年级（默认五年级）
- **学期**：上学期 / 下学期（年级右侧下拉，默认上学期）
- **单元**：Unit 1 ~ Unit 6（学期右侧下拉，按当前学期词库为该单元内容）；新增「全部单元」可一次性汇总本册所有单元（默认全部单元）
- **模式**：
  - **单词记忆**：单词 + 音标 + 中文对照词表，并附「看中文默写英文」自测区
  - **课本句子**：英文原句 + 中文翻译对照，便于背诵
- **数量**：可设抽取条数（0 = 全部），支持重新随机

**特色功能：**
- 每单元含 words（单词记忆）与 sentences（课本句子）两套数据，结构清晰，可直接在 `yingyu_data.py` 中增删改
- **功能区按钮**：生成 / 清空 / 导出PDF，一键操作
- **PDF 导出**：自动保存到项目根目录，文件名格式 `英语+模式+日+时+分`（如 `英语单词记忆25081004.pdf`）；同一分钟内多次导出自动追加 `_1`、`_2`、`_3` 区分（依赖 reportlab，缺失时提示）

## 🚀 快速开始

### 环境要求

- **Python**: 3.8 或更高版本
- **操作系统**: Windows 10/11（其他平台未充分测试）
- **屏幕分辨率**: 推荐 1280×800 或更高
- **网络**: 真题下载模块需要网络连接

### 安装依赖

```bash
pip install pillow reportlab requests beautifulsoup4 pypinyin opencc-python-reimplemented
```

### 运行程序

**方式一：命令行运行**
```bash
python main.py
```

**方式二：双击运行**
直接双击 `启动.bat` 文件即可启动程序。

### 首次运行

首次运行时会自动创建以下文件：
- `shuxue/.question_cache.json` — 数学题去重缓存
- `zhenti/.zhenti_history.json` — 真题搜索历史
- `zhenti/.zhenti_favorites.json` — 真题收藏夹
- `zitie/zitie_custom_data.json` — 字帖自定义内容（如用户修改过内容）

笔顺数据 `assets/stroke_data.json`（24MB）首次加载需要几秒，请耐心等待。

## 📖 使用指南

### 数学出题操作流程

#### 方式一：一键快速出题

1. 切换到 **"数学"** 标签页
2. 在 **"快速出题"** 区域选择年级（一年级~六年级）
3. 输入题目数量（默认 30 题，最大 10000 题）
4. 点击 **"一键出题"** 按钮
5. 查看预览区的题目和答案
6. 确认无误后点击 **"导出 PDF"**

> 一键出题按年级预设题型比例，基础题 60% + 提升题 40%，无需手动勾选。

#### 方式二：自定义出题

1. 切换到 **"数学"** 标签页
2. 在左侧四组区域（加减法/乘法/除法/四则混合）勾选需要的题型
3. 在每种题型右侧输入框设置题目数量（默认 20 题）
4. 可选：勾选 **"带括号"** 选项（仅对混合运算生效）
5. 可选：勾选 **"竖式"** 选项（增加答题空间）
6. 可选：取消 **"包含答案"** 可生成无答案版练习卷
7. 在 **"提升题"** 区域勾选进阶题型
8. 点击 **"生成题目"** 按钮预览
9. 确认无误后点击 **"导出 PDF"**

> **注意**：
> - 基础题（加减法/乘法/除法/四则混合）在 PDF 中分 4 列排列
> - 提升题（应用/几何/数论/逻辑）每题一行，2 列排版
> - 混合运算类题型始终排在每页最后
> - 几何类题目自动在 PDF 中嵌入图形（如长方形、三角形、立方体等）

### 字帖生成操作流程

#### 方式一：字帖生成模式

1. 切换到 **"字帖"** 标签页
2. 在 **"模式选择"** 中确保选中 **"字帖生成"**
3. 在 **"字体选择"** 中选择字体（默认楷体，可选行书/行楷/自定义）
4. 在左侧控件设置内容：
   - 选择 **年级**（如：四年级）
   - 选择 **版本**（目前支持人教版）
   - 勾选 **上册/下册**
   - 选择 **内容类型**（生字/词语/诗词/文言文）
5. 点击 **"一键导入"** 按钮加载课本内容到编辑框
6. 在右侧编辑框可以手动修改内容
7. 在 **"样式"** 区域选择格子样式（如：田字格）
8. 在 **"类型"** 区域选择显示方式（单字/整行/笔顺/带拼音/文章）
9. 可选：勾选 **"灰字"** 选项（浅色字迹便于描摹）
10. 点击 **"导出 PDF"** 生成字帖

> 不同内容类型会自动限制可用样式和显示类型，例如选择"拼音"时只有拼音格可用。

#### 方式二：空白模板模式

1. 切换到 **"字帖"** 标签页
2. 在 **"模式选择"** 中选中 **"空白模板"**
3. 在右侧数量输入框中输入页数（默认 5 页）
4. 在 **"样式"** 区域选择格子样式
5. 点击 **"导出 PDF"** 生成空白字帖

#### 方式三：古书/大楷练习

1. 在内容类型中选择 **"古书"** 或 **"大楷"**
2. **古书**：选择经典著作（千字文/道德经/三字经/弟子规/百家姓/阴符经/金刚经/心经），推荐竖行样式
3. **大楷**：默认填入古诗《山行》，推荐大楷本样式
4. 可选：切换简体/繁体（古书模式下）
5. 点击 **"导出 PDF"**

> **提示**：
> - "带拼音"类型会自动切换到生字格样式
> - "笔顺"模式需要 24MB 的笔顺数据支持，每字占一行展示笔画分解
> - 修改后的内容可以点击 **"保存"** 按钮保存到本地
> - 自定义字体可点击 **"预览"** 按钮从文件对话框选择 TTF/TTC/OTF 文件

### 作文练习操作流程

#### 课本作文模式

1. 切换到 **"作文"** 标签页
2. 在模式选择中选中 **"课本作文"**
3. 在左侧选择 **年级** 和 **学期**（上学期/下学期）
4. 在题目列表（固定 9 行，超出可滚动）中选择题目
5. 右侧显示：
   - **作文信息**：题目、年级、类型
   - **写作要求**：题目要求 + 字数要求（按年级自动匹配）+ 写作思路
   - **例文内容**：内置的 45 篇优秀范文之一
6. 可以直接编辑例文内容
7. 点击 **"保存例文"** 保存修改
8. 点击 **"导出 PDF"** 生成作文练习本

#### 中高考作文模式

1. 切换到 **"作文"** 标签页
2. 在模式选择中选中 **"中高考作文"**
3. 在左侧选择 **类型**（小升初/中考作文/高考作文）和 **年份**
4. 在题目列表中选择题目
5. 查看题目要求和例文（如有）
6. 点击 **"添加"** 按钮可添加自定义作文题目
7. 点击 **"导出 PDF"** 生成作文练习本

#### AI 写作助手

1. 选择任意作文题目（或在搜索框中输入题目）
2. 点击 **"AI 写作"** 按钮
3. 在弹出的对话框中选择平台：
   - **网页版**（免费推荐）：选择豆包/DeepSeek/通义千问等，自动复制提示词并打开网页
   - **自定义 API**：填写 API 地址、密钥、模型名称，选择平台预设一键填充
4. AI 生成的作文会自动填入例文区

> **各年级字数要求**：一年级 50-80 字 | 二年级 100-150 字 | 三年级 200-250 字 | 四年级 250-300 字 | 五年级 350-400 字 | 六年级 400-500 字

### 真题下载操作流程

#### 方式一：快捷搜索

1. 切换到 **"真题"** 标签页
2. 在 **"快捷搜索"** 区域直接点击对应年级按钮
   - 🔵 小学：一年级~六年级（浅蓝色）
   - 🟢 初中：七年级~九年级（浅绿色）
   - 🟠 高中：高一~高三（浅橙色）
3. 程序自动在 5 个平台搜索该年级的全部学科试卷
4. 等待搜索结果显示在列表区
5. 双击结果可打开试卷页面链接
6. 右键可选择：打开链接、复制链接、下载试卷、收藏、取消收藏

#### 方式二：自定义搜索

1. 在 **"自定义搜索"** 区域设置：
   - **平台**：第一试卷网、中小学试卷网、新一试卷、试卷网、心标教育
   - **年级**：一年级~高三
   - **学科**：根据年级动态显示可选学科（如四年级可选：全部/语文/数学/英语/科学）
   - **关键词**：可输入额外关键词（如"期末"、"期中"、"单元测试"）
2. 点击 **"搜索"** 按钮（或按回车键）
3. 等待搜索结果（状态栏会显示实时进度）
4. 可随时点击 **"停止"** 按钮中断搜索
5. 查看结果列表，双击或右键操作

#### 收藏夹和历史

- **收藏夹**：右键 → "收藏"，点击底部 **"收藏夹"** 按钮查看所有收藏的试卷
- **搜索历史**：自动记录每次搜索，点击底部 **"历史"** 按钮查看最近 100 条记录，双击可恢复搜索

> **提示**：
> - 搜索关键词支持智能解析，如输入"三年级数学期末"会自动识别年级=3、学科=数学、关键词=期末
> - 不同平台支持的学科不同，不支持的学科会被跳过
> - 下载的试卷保存在 `zhenti/` 目录下
> - 搜索结果按平台和学科分开搜索，先搜完一个平台再搜下一个

## ❓ 常见问题

### Q: 导出 PDF 时提示字体不存在？
A: 确保 `assets/fonts/` 文件夹中有对应的字体文件，或在字帖模块选择系统默认字体。程序会自动注册 fonts 文件夹中所有 TTF/TTC/OTF 文件。

### Q: 生成题目很慢？
A: 首次生成需要初始化去重缓存，后续会更快。如果仍然很慢，检查网络连接（真题模块需要网络）。一键出题模式下三年级以上包含大量提升题，生成时间略长。

### Q: 笔顺数据显示不完整？
A: 笔顺数据 `assets/stroke_data.json` 约 24MB，首次加载需要几秒。确保文件完整，没有被损坏。如个别汉字无笔顺数据，会自动回退到字体渲染模式。

### Q: 如何添加新的数学题型？
A:
1. 在 `shuxue_core.py` 的 `CATEGORY_NAMES` 中添加类型代码
2. 在 `MathProblemGenerator` 类中实现 `gen_xxx()` 方法（返回 `(题目, 答案)` 元组）
3. 在 `_GENERATOR_MAP` 中添加方法映射
4. 在 `shuxue_ui.py` 的 `_ATTR_MAP` 中添加 UI 映射
5. 在对应 Category 的 UI 布局中添加复选框

### Q: 真题搜索结果为空？
A:
1. 检查网络连接是否正常
2. 尝试更换平台（不同平台支持不同学科）
3. 检查所选平台是否支持该年级和学科
4. 尝试使用更简单的关键词
5. 某些平台可能需要科学上网

### Q: 作文例文可以修改吗？
A: 可以。在例文内容区域直接编辑文本，点击 **"保存例文"** 按钮即可保存修改到 `zuowen_data.json`。

### Q: 字帖内容可以自定义吗？
A: 可以。在右侧编辑框中输入或粘贴自定义内容，修改完成后点击 **"导出 PDF"**。如需持久保存修改，点击 **"保存"** 按钮。

### Q: 简繁体转换后如何恢复？
A: 在古书模式下，选择 **"简"** 即可将繁体转换回简体。转换基于 opencc 的 s2t/t2s 配置。

### Q: 如何备份我的数据？
A: 备份以下文件即可：
- `shuxue/.question_cache.json` — 去重缓存
- `zitie/zitie_custom_data.json` — 字帖自定义内容
- `zhenti/.zhenti_favorites.json` — 真题收藏夹
- `zhenti/.zhenti_history.json` — 搜索历史
- `zuowen/zuowen_data.json` — 作文扩展数据

### Q: 支持哪些年级？
A:
- 数学出题：1-6 年级
- 字帖生成：1-6 年级
- 作文练习：1-6 年级 + 中高考
- 真题下载：1-12 年级（小学 + 初中 + 高中）

### Q: 可以生成多页 PDF 吗？
A: 可以。内容超出单页时会自动分页，并在每页底部显示页码（如 "1/3"）。

### Q: 编译成 exe 后 PDF 导出路径对吗？
A: V1.1.1 已修复此问题。编译后的程序会将 PDF 导出到 exe 所在目录（而非临时目录）。
