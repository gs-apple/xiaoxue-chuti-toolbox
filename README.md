# 小学出题工具箱

一款专为小学生设计的全能练习题生成工具，支持数学、字帖、作文、真题四大模块，一键生成PDF练习卷，适合1-6年级日常练习和考前复习。

## ✨ 主要功能

### 📐 数学出题模块

**40+种题型，覆盖小学数学全知识点**

| 类别 | 题型 | 适用年级 |
|------|------|----------|
| **加减法** | 10以内、20以内、100以内、万以内、小数加减、分数加减 | 1-6年级 |
| **乘法** | 表内乘法、两位×一位、三位×一位、两位×两位、三位×两位、小数乘法、分数乘法、乘法简便运算 | 2-6年级 |
| **除法** | 表内除法、带余数除法、整除、除数是一位数、除数是两位数、小数除法、分数除法 | 2-6年级 |
| **四则混合** | 连加连减、加减乘、加减乘除、小数混合、分数混合 | 3-6年级 |
| **计算类** | 找规律填数、等差数列、简便运算、分数运用、比例应用 | 3-6年级 |
| **应用类** | 和差倍、年龄问题、植树问题、鸡兔同笼、盈亏问题、工程问题、行程问题、浓度问题、分配问题、测量计算 | 3-6年级 |
| **几何类** | 图形计数、图形分割、周长面积、立体图形、等积变形 | 3-6年级 |
| **数论类** | 奇偶分析、整除问题、余数问题、质/合问题、公约数/倍数 | 4-6年级 |
| **逻辑类** | 推理问题、统筹问题、最优化、抽屉问题、容斥问题 | 4-6年级 |

**特色功能：**
- ✅ 一键快速生成：选择年级和数量，自动生成综合练习卷

## 🚀 快速开始

### 环境要求

- **Python**: 3.8 或更高版本
- **操作系统**: Windows 10/11
- **屏幕分辨率**: 推荐 1280×800 或更高

### 安装依赖

```bash
pip install pillow reportlab requests beautifulsoup4 pypinyin opencc-python-reimplemented
```

### 运行程序

**方式一：命令行运行**
```bash
python main.py
```

**方式二：双击运行**
直接双击 `启动.bat` 文件即可启动程序

### 首次运行

1. 首次运行会自动创建以下文件和文件夹：
   - `.question_cache.json` - 数学题去重缓存
   - `question_bank.db` - 题库数据库
   - `zuowen.db` - 作文数据库
   - `zitie_custom_data.json` - 字帖自定义数据
   - `.zhenti_favorites.json` - 真题收藏夹
   - `.zhenti_history.json` - 真题搜索历史
   - `试卷下载/` - 真题下载目录

2. 笔顺数据 `stroke_data.json`（24MB）首次加载需要几秒，请耐心等待

## 📖 使用指南

### 数学出题操作流程

#### 方式一：一键快速出题

1. 切换到"数学"标签页
2. 在"快速出题"区域选择年级（默认：一年级）
3. 输入题目数量（默认：30题）
4. 点击"一键出题"按钮
5. 查看预览，确认无误后点击"导出PDF"

#### 方式二：自定义出题

1. 切换到"数学"标签页
2. 在"加减法"、"乘法"、"除法"、"四则混合"区域勾选需要的题型
3. 在每个题型右侧输入框设置该题型的数量（默认20题）
4. 可选：勾选"带括号"、"竖式"选项
5. 可选：勾选"包含答案"（默认勾选）
6. 点击"生成题目"按钮预览
7. 确认无误后点击"导出PDF"

**提示：**
- 基础题（加减法、乘法、除法、四则混合）会分4列排列
- 提升题（应用题、几何题、数论题等）每题一行
- 答案会显示在PDF末尾（如果勾选"包含答案"）

### 字帖生成操作流程

#### 方式一：字帖生成模式

1. 切换到"字帖"标签页
2. 在"模式选择"中确保选中"字帖生成"
3. 在"字体选择"中选择字体（默认：楷体）
4. 在左侧控件设置内容：
   - 选择年级（如：四年级）
   - 选择版本（如：人教版）
   - 勾选学期（上册/下册）
   - 选择内容类型（生字/词语/诗词/文言文）
5. 点击"一键导入"按钮加载内容
6. 在右侧编辑框可以修改内容
7. 在"样式"区域选择格子样式（如：田字格）
8. 在"类型"区域选择显示方式（单字/整行/笔顺/带拼音/文章）
9. 可选：勾选"灰字"选项
10. 点击"导出PDF"生成字帖

#### 方式二：空白模板模式

1. 切换到"字帖"标签页
2. 在"模式选择"中选中"空白模板"
3. 在"数量"输入框中输入页数（默认5页）
4. 在"样式"区域选择格子样式
5. 点击"导出PDF"生成空白字帖页

#### 方式三：古书/大楷练习

1. 切换到"字帖"标签页
2. 在内容类型中选择"古书"或"大楷"
3. 选择经典著作（古书）：千字文、道德经、三字经等
4. 选择格子样式（古书推荐竖行，大楷推荐大楷本）
5. 可选：切换简体/繁体
6. 点击"导出PDF"

**提示：**
- 不同内容类型对应不同的可用样式
- "带拼音"类型会自动切换到"生字格"或"拼音格"
- 笔顺模式需要24MB的笔顺数据支持
- 修改后的内容可以点击"保存"按钮保存

### 作文练习操作流程

#### 课本作文模式

1. 切换到"作文"标签页
2. 在模式选择中选中"课本作文"
3. 在左侧选择年级和学期
4. 在题目列表中选择题目
5. 在右侧查看：
   - 作文题目和要求
   - 字数要求（按年级自动显示）
   - 写作思路提示
   - 优秀例文
6. 可以编辑例文内容
7. 点击"导出PDF"生成作文本
8. 可选：点击"保存例文"保存修改

#### 中高考作文模式

1. 切换到"作文"标签页
2. 在模式选择中选中"中高考作文"
3. 在左侧选择类型（小升初/中考作文/高考作文）和年份
4. 在题目列表中选择题目
5. 查看题目要求和例文
6. 点击"添加"按钮可添加自定义题目

#### AI写作助手

1. 选择任意作文题目
2. 点击"AI写作"按钮
3. 选择AI平台（如：豆包、DeepSeek等）
4. 程序会自动：
   - 复制写作提示词到剪贴板
   - 打开AI写作网页
5. 粘贴提示词即可让AI生成作文

**提示：**
- 例文编辑后可点击"保存例文"保存到本地
- PDF导出格式为标准作文本，包含日期、正误格
- 字数要求按年级自动匹配：
  - 一年级：50-80字
  - 二年级：100-150字
  - 三年级：200-250字
  - 四年级：250-300字
  - 五年级：350-400字
  - 六年级：400-500字

### 真题下载操作流程

#### 方式一：快捷搜索

1. 切换到"真题"标签页
2. 在"快捷搜索"区域点击对应年级按钮
   - 小学：一年级~六年级（蓝色）
   - 初中：七年级~九年级（绿色）
   - 高中：高一~高三（橙色）
3. 程序自动搜索并显示结果
4. 双击结果可打开链接
5. 右键可选择：复制链接、下载试卷、收藏

#### 方式二：自定义搜索

1. 在"自定义搜索"区域设置：
   - 平台：第一试卷网、中小学试卷网等
   - 年级：一年级~高三
   - 学科：全部/语文/数学/英语/科学/物理/化学等
   - 关键词：可输入额外关键词（如"期末"、"期中"）
2. 点击"搜索"按钮
3. 等待搜索结果显示
4. 查看结果列表
5. 右键操作或双击打开

#### 收藏夹和历史

1. **收藏夹**：
   - 在结果列表右键点击"收藏"
   - 点击"收藏夹"按钮查看已收藏的试卷
2. **搜索历史**：
   - 程序自动记录每次搜索
   - 点击"历史"按钮查看搜索记录

**提示：**
- 搜索关键词支持智能解析，如"三年级数学"会自动识别年级和学科
- 不同平台支持的学科不同，不支持的学科会显示为空
- 下载的试卷保存在`试卷下载/`目录

## ❓ 常见问题

### Q: 导出PDF时提示字体不存在？
A: 确保 `fonts/` 文件夹中有对应的字体文件，或在字帖模块选择系统默认字体。

### Q: 生成题目很慢？
A: 首次生成需要加载去重缓存，后续会更快。如果仍然很慢，检查网络连接（真题模块需要网络）。

### Q: 笔顺数据显示不完整？
A: 笔顺数据 `stroke_data.json` 约24MB，首次加载需要几秒。确保文件完整，没有被损坏。

### Q: 如何添加新的数学题型？
A: 
1. 在 `shuxue_core.py` 的 `CATEGORY_NAMES` 中添加类型代码
2. 在 `MathProblemGenerator` 类中实现 `gen_xxx()` 方法
3. 在 `shuxue_ui.py` 的 `_ATTR_MAP` 中添加映射
4. 在UI布局中添加对应的复选框

### Q: 真题搜索结果为空？
A: 
1. 检查网络连接
2. 尝试更换平台
3. 检查所选平台是否支持该年级和学科
4. 尝试使用更简单的关键词

### Q: 作文例文可以修改吗？
A: 可以。在例文内容区域直接编辑，点击"保存例文"按钮即可保存修改。

### Q: 字帖内容可以自定义吗？
A: 可以。在右侧编辑框中输入或粘贴自定义内容，然后点击"导出PDF"。

### Q: 简繁体转换后如何恢复？
A: 在古书模式下，选择"简"即可将繁体转换回简体。

### Q: 如何备份我的数据？
A: 备份以下文件：
- `.question_cache.json`
- `zitie_custom_data.json`
