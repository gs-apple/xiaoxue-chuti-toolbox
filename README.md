# 小学出题工具箱

给小学家长和老师用的一套本地小工具：**出数学题、印字帖、找作文、下真题、练英语、做趣味题**，六件事都在一个窗口里，导出 PDF 直接打印。

Windows + Python + tkinter，单窗口 700×700，绿色免安装、无后台服务、不收集任何数据。除「真题」需要联网抓取公开网页外，其余功能全部离线运行。

当前版本 **V1.2.5**（标题栏显示 `小学出题工具箱 V1.2.5 —by:Shaowei`）。

## 下载与安装

### 方式一：直接下 exe（推荐给家长）

到 [Releases](https://github.com/gs-apple/xiaoxue-tool/releases) 页面下载最新的
`xiaoxue-chuti-toolbox_V1.2.5_win64.zip`，**解压到任意文件夹**（不要在压缩包里直接双击），然后双击里面的 `小学出题工具箱.exe`。

- 无需安装 Python，无需联网下载依赖；
- 首次运行若弹出 Windows SmartScreen 提示，点「更多信息」→「仍要运行」（程序未做代码签名）；
- 整个文件夹可以拷到 U 盘，换电脑照常使用，数据都在同一目录内。

### 方式二：跑源码（推荐给想改数据的老师）

```bash
git clone https://github.com/gs-apple/xiaoxue-tool.git
cd xiaoxue-tool
pip install -r requirements.txt
python main.py
```

Windows 下也可以直接双击 `启动.bat`（会自动找 `pythonw.exe`，不弹黑窗口）。

## 功能详解

窗口是一个 7 标签页的 Notebook，从左到右：**说明 / 数学 / 字帖 / 作文 / 真题 / 英语 / 趣味**。

### 说明

打开软件默认显示的页面。三个分组栏：

- **📋 软件功能**：六个模块逐条说明；
- **💝 打赏支持**：感谢语 + 特别感谢（52pojie 的 王丶 先生）+ 微信赞赏码（图片内嵌在代码里，不依赖外部文件）；
- **⚠️ 安全提醒**：本软件纯 AI 编写，免费分享，不收任何费用，谨防被骗！

### 数学

| 分区 | 内容 |
|---|---|
| 加减法 | 10 以内 / 20 以内 / 100 以内 / 万以内 / 小数加减 / 分数加减 |
| 乘法 | 表内乘法 / 两位×一位 / 三位×一位 / 两位×两位 / 三位×两位 / 小数乘法 / 分数乘法 / 乘法简便运算 |
| 除法 | 表内除法 / 带余数除法 / 整除 / 除数是一位数 / 除数是两位数 / 小数除法 / 分数除法 |
| 四则混合 | 连加连减 / 加减乘 / 加减乘除 / 小数混合 / 分数混合 |
| 快速出题 | 选年级（一~六年级）一键出题 |
| 附加选项 | 带括号、竖式、包含答案 |
| 提升题 | 计算类 / 应用类 / 几何类 / 数论类 / 逻辑类，共五类题型 |
| 功能区 | 生成题目、清空预览、全部清空、导出 PDF |

每个题型都是**独立的勾选框 + 题量微调框**，可以只出「表内乘法 20 题」这种极小组合，也可以一次混搭十几类。题目先在下方「题目预览」里看，满意了再导出；勾选「包含答案」时，PDF 会另起一页生成答案页（题号与答案两列对齐，一道题不会跨页断开）。

> 数学模块按「年级 + 题型」生成，**不依赖任何教材版本**，五年制/六年制小学都能用。

### 字帖

- **汉字字帖**：按年级 + 教材版本 + 上下册取「生字表 / 词语表 / 古诗词 / 文言文」，也可完全自己输入文字；
- **格子样式**（10 种）：田字格、方格、米字格、数学格、生字格、拼音格、作文本、教案格、大楷本、竖行；选「生字格」会自动切到带拼音的类型，两者联动；
- **字体**：默认 / 楷体 / 行书 / 行楷 / 自定义（把字体丢进 `assets/fonts/` 即可选到），另可一键**简体 ↔ 繁体**转换；
- **笔顺演示**：内置 22.9 MB 笔顺数据（`assets/stroke_data.json`），可逐笔演示；
- **空白模板**：不填内容，直接出空白格子；
- 导出 A4 PDF 打印，字格尺寸按毫米定义，打印出来可以直接照帖练字。

### 作文

两种模式：

**课本作文**（默认进「五年级 / 上学期」）

- 1–6 年级上下册同步单元习作，共 86 题；
- 每道题带写作要求、写作思路、字数标准（下表）与范文例文；
- 字数标准按年级固定（与课标不完全一致，是本软件的约定）：

| 年级 | 一 | 二 | 三 | 四 | 五 | 六 |
|---|---|---|---|---|---|---|
| 字数 | 50-80 | 100-150 | 200-250 | 250-300 | 350-400 | 400-500 |

**中高考作文**

- 类型下拉：小升初 / 中考作文 / 高考作文 / 满分原文；
- 年份下拉固定 **2030 → 2023**，默认 **2026**；「满分原文」默认 **2020**；
- 高考真题 2024(7 题) / 2025(6 题) / 2026(6 题)；满分原文 2 篇（2001《赤兔之死》、2020《生活在树上》）；
- 小升初 / 中考两类的题库已清空（原先只收了甘肃平凉本地卷，外地用不上），**入口保留**，可用「添加题目」把自己所在地的卷子录进去，下次打开还在；
- 每道题可一键复制提示词，粘到 AI 网页版让它按提示写范文；也能导出练习纸 PDF。

### 真题

聚合 5 个公开试卷站，按 年级 / 学科 / 年份 / 关键词 筛选，结果按平台混排：

| 平台 | 下载方式 | 每平台翻页 |
|---|---|---|
| 第一试卷网 shijuan1.com | **直链直下**（docx/pdf） | 3 页 |
| 中小学试卷网 szxuexiao.com | 打开试卷页，自己点下载 | 20 页 |
| 新一试卷 yishijuan.com | 打开试卷页，自己点下载 | 20 页 |
| 试卷网 shijuan.net | 打开**详情页**，按页面提示拿提取码 | 20 页 |
| 心标教育 xbjy.com | 打开页面（该站无分页规律，只抓第 1 页） | 1 页 |

- 平台下拉首项是 **「全部平台」**，一次搜索依次跑完五家；某家没有这个学科时自动跳过；
- 每条结果前有复选框，可多选后**批量下载 / 批量打开页面**（点表头可全选，双击行仍可单独打开）；
- 收藏夹：收藏的试卷记在 `zhenti/.zhenti_favorites.json`；
- 下载安全：只接受 `rar / zip / 7z / doc / docx / pdf / xls / xlsx` 八种扩展名，单文件上限 100 MB，落盘前拦截 Windows 保留设备名（CON、NUL、COM1…）。

### 英语

- 两套教材：**人教版(PEP)** 与 **陕旅版**，均覆盖三~六年级上下册；
- 内容四选一：**单词 / 课文 / 表达句 / 音标**（音标是国际音标表，按元音、辅音分组，每组附 3 个例词）；
- 两种用途：**字帖（描红）** 与 **出题（默写）**；出题方向可选 随机出题 / 汉译英 / 英译汉；
- 字帖排版：默认四线三格（每行 10 mm），可设灰字描红、字体（含「舒窈衡水体」等手写风字体）、横排或竖排，导出 A4 PDF；
- 「常用」下拉内置 27 个主题词表：学习用品、人体、颜色、动物、人物、职业、食品饮料、水果蔬菜、衣服、交通工具、杂物、地点、课程、国家城市、气象、景物、植物、星期、患病、季节、方位、月份、数词、形容词、介词、代词、动词；
- 单词行带音标，三会词前标 `*`；
- 数据是纯文本，记事本改完保存，切回软件即生效，**不用重启**。

### 趣味

四个子标签，各带设置区、预览区、导出 PDF：

| 子模块 | 说明 |
|---|---|
| 简笔画 | 按分类挑选图案，分步临摹；两种模式：描红练习 / 对比临摹；可随机抽取 |
| 迷宫运笔 | 随机生成迷宫，练运笔，可生成答案 |
| 数独 | 按难度生成，可生成答案 |
| 幻方 | 随机生成，可生成答案 |

## 启动方式

**双击 `启动.bat`**，或命令行：

```bash
python main.py
```

`启动.bat` 的查找顺序：本目录 `pythonw.exe` → `E:\Program Files (x86)\Python\pythonw.exe`（作者本机路径，对外部用户无影响）→ PATH 里的 `pythonw` → 依次回退到 `python.exe`。找到后用 `start` 在后台启动，`bat` 窗口立刻关闭，不会留黑窗口。

程序带**单实例保护**：重复打开会把已在运行的窗口拉到前台，不会启动第二个实例。

启动过程做了显示优化：窗口在构建期间保持隐藏，六个标签页全部创建完成后才一次性居中显示，所以打开即是完整的「说明」页，不会看到白屏闪烁。

## 数据文件与自定义

三个模块的数据都能自己改，改完不需要重装、多数情况也不需要重启。

### 英语：`yingyu/data/<版本>/<年级>.txt`

纯文本、UTF-8，记事本直接改。格式：

```
[上学期] Unit 1
.单词
team /tiːm/ 队；组            ← 单词 /音标/ 中文
*name /neɪm/ 名字            ← 行首 * = 三会词
.课文
Hello! || 你好！              ← 英文 || 中文
.表达句
What's this? || 这是什么？
```

- `[学期] Unit N` 起一个新单元，没内容的块可以整块不写；
- 加词 = 在 `.单词` 下面加一行；加单元 = 新起一个分节；
- 写回采用「临时文件 → 落盘 → 原子替换」，并在 `data/.bak/` 留备份，不会写坏原文件；
- 保存后切回软件即生效（内部按文件修改时间判断，不需要重启）。

### 作文：`zuowen/zuowen_data.json`

- 顶层结构：`TEXTBOOK_COMPS`（课本习作）、`EXAMPLE_ESSAYS`（例文，键为 `年级/学期/题目`）、`GAOKAO`、`MANFEN`、`PICTURE_WRITING`；
- 一般不手改：界面里「添加题目」会直接写这个文件，同样原子替换；
- 想批量导入自己学校的卷子，用「添加题目」最省事。

### 字帖：`zitie/zitie_data.py`

## 自己打包成 exe

仓库里没有提交打包产物，需要的话照下面这条命令（PyInstaller 6.x）：

```bash
python -m PyInstaller main.py --name "小学出题工具箱" --noconfirm --clean \
  --windowed --contents-directory . --icon "assets/favicon.ico" \
  --add-data "assets;assets" \
  --add-data "yingyu/data;yingyu/data" \
  --add-data "yingyu/yingyu_common.py;yingyu" \
  --add-data "yingyu/yingyu_phonetic.py;yingyu" \
  --add-data "quwei/images;quwei/images" \
  --add-data "quwei/app_data.json;quwei" \
  --add-data "zuowen/zuowen_data.json;zuowen" \
  --add-data "zitie/zitie_custom_data.json;zitie" \
  --add-data "zhenti/.zhenti_favorites.json;zhenti"
```

两个要点：

- `--contents-directory .` 把运行库摊到 exe 同级，这样程序里两套数据路径（`constants.BASE_DIR` 与模块自身的 `__file__` 目录）指向同一份文件，不用改业务代码；
- `yingyu_common.py` / `yingyu_phonetic.py` 必须当普通数据带进去——英语模块运行时是按 `__file__` 目录读这两个 `.py` 的。

产物在 `dist/小学出题工具箱/`，约 116 MB（其中字体 43 MB、笔顺数据 22.9 MB），压缩后约 72 MB。发布时请把整个目录打成 zip，**不要只发 exe**。

## 已知限制

- **真题依赖网页结构**：五个站点任何一家改版，对应的解析就会失效（不会崩，只是搜不到），改配置即可，测试文件里有各站的真实片段可对照；
- **试卷网要提取码**：`shijuan.net` 的下载链接藏在详情页，需要关注公众号拿提取码，软件只负责把详情页打开，不代取；
- **下载安全线是白名单**：超过 100 MB、非白名单扩展名一律拒绝，所以个别特殊格式的卷子会下不下来；
- **字体版权**：`assets/fonts/` 里的字体来自网络（含方正、汉仪、康熙字典体等商业字体），仅供个人学习使用，商用请自行购买授权；
- **打包体积大**：字体 + 笔顺数据占了 66 MB，属于数据体积，压不下去；
- 只在 Windows 上验证过，macOS / Linux 未测试。
