# 小学出题工具箱

给小学阶段家长和老师用的一套本地小工具：出数学题、印字帖、找作文、下真题、练英语、做趣味题，全部离线运行（真题功能需要联网），导出 PDF 直接打印。

Windows + Python + tkinter，单窗口 700×700，无安装、无后台服务、不收集任何数据。

## 功能

| 标签页 | 能做什么 |
|---|---|
| **说明** | 软件功能说明、打赏信息、安全提醒（打开软件默认显示） |
| **数学** | 加减法、乘法、除法、四则混合、一键出题；提升题含计算/应用/几何/数论/逻辑；支持带括号、竖式、包含答案；一键导出 A4 PDF |
| **字帖** | 汉字字帖与空白模板；网格可选田字格、方格、米字格、生字格、四线三格、作文本、教案格、大楷本、竖行；字体可选默认/楷体/行书/行楷/自定义；内容按年级+教材版本+上下册取生字、词语、古诗，也可自己输入；导出 PDF 直接打印 |
| **作文** | 课本作文（1–6 年级上下册同步单元习作 + 范文）；中高考作文（高考真题、历年满分原文，小升初/中考可自行录入本地卷）；一键复制提示词到 AI 网页版；导出练习纸 |
| **真题** | 聚合 5 个试卷站（第一试卷网、中小学试卷网、新一试卷、试卷网、心标教育）的搜索结果；按年级/学科/年份/关键词筛选；列表勾选后批量下载，直链自动下载、需提取码的自动打开详情页；收藏夹 |
| **英语** | 人教版(PEP)/陕旅版 三至六年级单词、课文、表达句；常用词句与音标分类；四线三格英语字帖（可灰字描红），导出 PDF；数据文件可直接用记事本编辑 |
| **趣味** | 简笔画、迷宫运笔、数独、幻方，按难度生成，可带答案，导出 PDF |

## 环境要求

- Windows 10/11
- Python 3.9 及以上（开发环境为 3.13）
- 依赖：`reportlab`、`Pillow`、`requests`

```bash
pip install -r requirements.txt
```

## 启动

双击 `启动.bat`（优先用 `pythonw.exe`，不弹控制台窗口），或在项目根目录执行：

```bash
python main.py
```

程序自带单实例保护：重复打开会把已运行的窗口拉到前台，不会启动第二个。

## 目录结构

```
main.py            主窗口与标签页装配
constants.py       路径、颜色等常量
widgets.py         自绘渐变按钮
assets/            字体文件、笔顺数据、图标
shuxue/            数学出题
zitie/             汉字字帖
zuowen/            作文（zuowen_data.json 为题库与范文）
zhenti/            真题搜索与下载（zhenti_core 平台配置、zhenti_ui 界面）
yingyu/            英语（data/<版本>/<年级>.txt 为词句数据）
quwei/             趣味出题
dashang/           说明页
tests/             zhenti 模块的单元测试（pytest）
```

## 数据文件

- **英语**：`yingyu/data/<版本>/<年级>.txt`，纯文本，格式为 `[学期] Unit N` 分节 + `.单词/.课文/.表达句` 块；词行格式 `单词 /音标/ 中文`，句行 `英文 || 中文`。用记事本改完保存，回到软件即生效，无需重启。
- **作文**：`zuowen/zuowen_data.json`。界面里的「添加题目」会直接写入该文件，写入时先写临时文件再原子替换，不会写坏原文件。
- **真题**：下载的试卷默认保存在程序所在目录（即 `main.py` 同级），下载时可以另选文件夹。

## 测试

```bash
python -m pytest tests -q
```

覆盖真题模块的列表页解析、分页规则、下载类型判定、年级识别与文件名白名单。
